# Banner 制作与批量交付

把运营的原图制作成可预览、可交付网站的主题。复用现有分层和工具，以最少的必要处理完成任务；输出质量以原图内容、接触关系和实际动画为准。

## 识别任务与环境

- 先检查输入尺寸、已有源工程／遮罩、目标比例和明确的编辑要求。保留原文件。已有有效环境与未变验证证据直接复用。
- 默认锁定原图的全部文字、Logo、字幕、日期、人物、道具和相对位置。“保留人物”不授权删掉其他内容。缩窄容器也不能擅自隐藏标题、换人、重排或裁掉信息；用户明确要求的改动优先。
- 读取 [工具与工程](references/production.md)，确认源码与 doctor 的能力字段。首次准备或工具变化时检查环境，同一任务不反复扫描仓库、安装依赖或重读全部文档。
- 只有需要新分层／补景时读 [图像制作](references/artwork.md)；批量再读 [批量处理](references/batch.md)。验收使用 [验收](references/acceptance.md)。

## 制作

1. **复用优先。** 已有原尺寸遮罩或分层时直接使用。原图已是 4:1 时保留整幅构图，默认按原生分辨率输出电脑端、等比生成紧凑端，不无条件放大到 4K。新分层优先使用已有分割工具，不把逐点描大量轮廓当默认流水线。
2. **先定空间关系。** 远景移动最少；人物与坐具、接触阴影和支撑地面归到同一中景层；前景遮挡层移动较多。沿真实物体边缘分层，保持原图坐标、比例和透视。源图本来悬空的对象保持其原设计。
3. **保真准备。** 使用 theme:preserve 生成受保护源工程；它只在被移动图层遮住的位置使用补景，其余背景及文字保持原图。所有人物和前景仍取原像素。已有其他工程可继续使用，但不能把未经原图对照的结果称为内容保真。
4. **快速出样。** 先运行 theme:build --quick --ubits，一次得到主题、个人中心预览和网站包。此模式保留几何与完整内容检查，只省略大型构图拼图。使用现成预览模板，不为每张海报重写页面或测试脚本。
5. **一次收敛。** 对照原图查看静止、左右极限和紧凑状态；检查文字、拼接处、人物脚下和前景遮挡。只修改有证据的问题。交付前去掉 --quick 生成一次精简构图图；不无故重复完整测试、预览和压缩。
6. **交付。** 网站使用 artifacts/website.zip，运营使用离线预览与报告，源工程单独归档。说明动效类型、实际检查范围和导出耗时；不把已有遮罩条件下的构建秒数宣传为任意新海报的全部制作时间。

## 批量与复核

- 未准备好的原图保持 needs_preparation，成功项独立保存。不能把占位图、单张整体平移冒充人物独立视差；改变用户要求的动效类型要明确说明。
- 默认一个候选，明显缺陷局部修正一次；按用户要求的次数／预算执行。脚本不调用付费图像 API，也不虚构费用。
- 源图、参考图、生成器、构建选项及产物摘要未变时复用缓存；有变化重新验证。单张 build 也默认复用已验证结果，--rebuild 可强制重建。
- 画面检查后才记录 review，区分 agent 自检与实际运营确认。自动检查通过不等于人物接地、边缘拼接或生产部署已经验收。

## 交付说明

简要给出预览、网站包、源工程与验证结论。说明是否保留全部原图内容、是否使用 AI 补景、是否有未验证设备。不要仅列测试数量；必须说明原图对照、接缝和接地检查结果。
