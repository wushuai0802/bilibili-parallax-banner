# 验收与交付

## 自动检查

每项必须通过 theme:build 和 theme:check 的图片解码、实际透明、尺寸、图层引用、声明宽度及五个位移位置检查。保持默认构图检查图输出。配置变动后重新验证；已有输入和验证未变时可复用证据。

生成器依据制作方标注的矩形计算安全区，不会自动寻找人脸，也不证明所有连续宽度都安全。抠图审美、前景实际像素遮脸、人物身份及网页真实文字需要单独查看。

## 画面复核

查看至少电脑、紧凑构图以及静止、最左、最右：

- 头部、饰品与重要物体完整，人物没有被拉伸；所有重要人物均有对应区域标注。
- 背景没有空洞、残影或第二个人物；透明层没有棋盘格、底色或明显白边。
- 前景不挡脸，人物下缘自然收口；背景和人物保持同一色调、光线与清晰度。
- 留白符合网站实际文字、左右箭头和底部指示条；带文字时检查真实渲染后的大小。
- 静态、加载失败和减少动态模式能显示合格海报；静态任务的位移参数为零。

UBits 使用项目模板登记的容器宽度，重点查看 362、657、758、768、994、1244、1638px 及分界附近。个人中心开合改变的是 Banner 容器，不能仅按浏览器宽度判断。集成支架在 examples/ubits/，原站实测约定在 docs/UBITS.md。

若现有环境支持浏览器，打开实际生成页检查电脑鼠标、紧凑自动动效、原站接入时的轮播与侧栏；可以运行项目相关浏览器测试。用户要求完整网站验收而环境缺失时明确列出未验证部分，不将构图图充当浏览器截图。实体手机触摸、独立服务端移动模板和生产 CSP 只有实际检查后才能确认。

## 结果状态

| 状态 | 含义 |
| --- | --- |
| approved | 当前源／产物摘要下已记录画面复核，复核者与范围见记录 |
| needs_review | 工程自动检查成功，尚未记录画面通过 |
| changes_requested | 画面复核要求修改 |
| needs_preparation | 原图仍需图像工具／美工准备源工程 |
| failed | 导出或数据检查失败 |

自动通过不能升级为运营确认。输出损坏、源图或生成器改变时复核失效。approved 也不表示已经上传、发布或接入正式站点。

## 交付

- 网站：完整的 artifacts/theme.zip，包含 theme.json、两端图片及清单、预览与报告。保持哈希文件名和目录结构。
- 运营：可打开的 index.html 或 artifacts/offline.html、构图图、实际检查说明与待处理项。
- 后续编辑：project.json、source/ 原素材及实际来源信息，独立于网站部署包。
- 批量：总览 index.html、batch-state.json 和各项主题包。说明总数量、各状态数量及实际完成的浏览器／设备验证。

不要承诺任意海报都能无人工处理完成；遇到不合格项目给出具体失败原因与下一步素材需求，其他合格项目照常交付。
