# 交给AI的Banner图片制作任务

v1.3优先采用[源工程任务书](../theme-project/AI-BRIEF.md)，准备一套源图与标注后由工具导出。本文件保留给已经完成两端画布、希望手工交付的制作方。

请按项目的 `docs/IMAGE-SPEC.md`，使用我提供的参考图片制作一个新Banner主题。使用 `templates/theme/` 作为目录和配置起点，保留可复用组件的接入方式。

请完成以下交付：

1. 使用一套原始分层素材，分别制作电脑3840×432和手机1125×600的构图；每端包含完整画布的背景、透明主体、透明前景和不透明合成海报。
2. 手机重新安排人物比例与位置，保留全部关键头部、物体和文字留白。背景去掉重复人物并补全抠图空洞，检查移动两端是否露底。
3. 独立人物采用contain并底部对齐；需要对齐的背景采用canvas。清单、图片尺寸、导出倍率保持一致，不能裁掉透明画布边缘。
4. 标题、Logo、按钮与搜索框交给网页实现。记录我网站实际需要的文字区域，避免把界面文字烘焙进图片。
5. 更新desktop/banner.json、mobile/banner.json和theme.json；根据新图登记每个关键主体的protectedRegions，不能照抄占位矩形或芙莉莲坐标。
6. 记录实际素材作者、参考来源与许可；保留可编辑源文件。
7. 运行 `npm run validate:theme -- <新主题目录>/theme.json`，修复尺寸、透明、主体越界及文字区冲突，并检查实际画面的抠图、遮挡和两端网页效果。

最终提供完整主题目录、可编辑源文件、两端静止与左右位移的预览，以及校验结果和未能验证的项目。请根据原图实际情况说明需要补绘的部分。
