# v1.2 构图与交互验证

## 自动检查

运行 `npm run check`。v1.2.0发布时包含59项测试，并解码校验默认、桌面和手机素材；当前总数以命令输出为准。新增的配对主题图片验收见[图片交付规范](IMAGE-SPEC.md)。

构图测试读取 `examples/frieren/composition.json` 中的三个人物头部区域，在280–5120px共21种宽度、5个位移进度下核对四边安全距离。背景覆盖与主体容纳分别计算；人物图层不再因背景出血而放大。

JSDOM交互测试覆盖鼠标归位、横向拖动、纵向放行、横幅外第二个触点、宿主缩放、减少动态、资源失败、加载中销毁、断点重建、模式保留与页面缓存恢复。

离线集成测试直接执行生成的完整HTML，解码其中真实的内嵌图片，分别在手机`content://`地址和桌面`file://`地址确认三层全部就绪，不依赖HTTP素材或外部脚本。
